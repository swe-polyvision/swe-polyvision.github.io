Data/Agents

Agent Sessions & Tool Trajectories

Session-level data built for agent training. We capture full action sequences, tool calls, and environment-state changes from real dev sessions — including failure, backtracking, and recovery, which is where long-horizon capability comes from.

Coverage

  • Real dev sessions
  • Tool calls
  • Environment state
  • Failure recovery
  • Long-horizon execution

Deliverables

  • Session logs
  • Action sequences
  • State snapshots
  • Result verification
  • Failure causes & trajectory summaries

The pipeline

From source to acceptance

We don't hand-label a pile and ship it. Every category moves through a closed, instrumented loop — generated to a brief, checked by machines, adjudicated by experts, and traceable end to end — but the path each data type takes is its own.

  1. 01

    End-to-End Capture

    Complete sessions are recorded across real and simulated environments, preserving every tool call, observation, and intermediate decision from first prompt to final outcome.

  2. 02

    State Alignment

    Each action is pinned to the environment state it acted on, so the whole trajectory stays faithfully replayable and every step can be re-grounded in its exact context.

  3. 03

    Scripted Verification

    A deterministic check settles the outcome of each consequential action, turning a loose transcript into a sequence of verified results with unambiguous success and failure signals.

  4. 04

    Failure & Recovery Labeling

    Dead ends, backtracks, and recoveries are labeled explicitly, capturing the corrective behaviour that is precisely where durable long-horizon capability is learned.

  5. 05

    Trajectory Summarization

    Each session is distilled into a structured summary of goal, plan, key branches, and recovery paths, making long multi-hundred-turn traces legible and reusable.

  6. 06

    Consistency Review

    A review pass reconciles the summary against the verified steps, ensuring the recorded narrative matches what actually happened in the environment.

  7. 07

    Stratified Sampling

    A final stratified draw across task types, horizons, and failure modes fixes the distribution and guards quality before the trajectories ship.

↺

Every run emits a learning signal that feeds back into the source set — the pipeline tightens itself, batch over batch.
