BENCHMARK

Seeing more images is not the same as reasoning across them.

SWE-PolyVision evaluates whether an agent can connect observations distributed across images, infer a shared repository-level cause, and produce a verified repair.

  • 92real software issues
  • 405model-readable visual inputs
  • 100%multi-image tasks
  • 4.40mean inputs per task

EVALUATION PROTOCOL

One task.
Three access modes.

The issue, repository, agent scaffold, budget, environment, and verifier stay fixed.
